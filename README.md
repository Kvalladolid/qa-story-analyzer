
# QA Story Analyzer

Herramienta para ayudar a equipos de QA a analizar historias de usuario mediante IA.

## Funcionalidades actuales

* Análisis de User Stories
* Identificación de riesgos
* Casos funcionales
* Casos negativos
* Casos límite
* Recomendaciones de automatización
